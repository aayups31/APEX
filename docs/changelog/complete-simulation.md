# Complete Simulation Edition Changelog

## 0.2.0 — August 6, 2026

### Added

- no-game complete simulation start guide;
- `apexsim.sim_core` package;
- six-car race demo and `simulate-race` CLI command;
- track reconstruction from canonical telemetry;
- vehicle, tyre, fuel, energy, weather, flags, traffic, DRS, pits and race ordering;
- lap/stint/event/quality artifacts;
- calibration, replay, hybrid residual and strategy planner interfaces;
- source manifests and real-data helper scripts;
- 12 complete architecture/build/evaluation/legal documents;
- experiment, dataset and model-card templates;
- JSON scenario schema;
- 66-task backlog;
- six new tests.

### Preserved

- original APEX apprenticeship, PDFs, notebooks, engine, UI, API, pipeline and verified run artifacts.

### Deprecated as a requirement

- F1 25 game/UDP telemetry. The original chapter remains educational material, but the complete-simulation path does not depend on the game.

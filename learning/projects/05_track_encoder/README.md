# Project: Track Segment Encoder

## Mission
Encode local track geometry and fuse it with telemetry.

## Build order
1. Write the input/output contract.
2. Implement the smallest correct version.
3. Add tests before optimization.
4. Create one visual diagnostic.
5. Break a key assumption deliberately.
6. Compare at least two implementation choices.
7. Write a decision record.

Run: `python main.py`

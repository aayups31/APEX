# APEX Learning Resources

This directory contains the optional engineering apprenticeship developed alongside APEX.

It is included to document the learning, experimentation, and debugging process behind the project. The production simulator does not depend on this material.

## Contents

The learning resources include:

- a structured engineering textbook;
- executable labs;
- smaller milestone projects;
- a debugging casebook;
- a field workbook;
- research-reading material;
- annotated source-code companions;
- document-generation tools.

## Purpose

These resources were created to build understanding before introducing advanced simulation and machine-learning components.

Topics include:

- numerical integration;
- telemetry contracts;
- data leakage;
- time-series windows;
- regression baselines;
- GRUs and recurrent memory;
- state-space models;
- RSSMs and world models;
- model-predictive control;
- planner exploitation;
- production ML pipelines.
